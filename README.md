# Сверка платежей НВОС (веб)

Веб-интерфейс сверки деклараций с платёжными поручениями за квартал
(авансовые платежи = 1/4 годовой суммы платы).

## Запуск

Двойной клик по `start.bat` — откроется браузер на http://127.0.0.1:8021.

## Использование

1. Выбрать отчётный период: квартал (1/2/3, ожидание = 1/4 годовой суммы)
   или **год** (ожидание = вся годовая сумма).
2. Указать **год периода платежа** (по умолчанию текущий): учитываются только
   платежи этого года, например `КВ.01.2026` при годе 2026. Пустое поле —
   любой год.
3. Загрузить выгрузку деклараций за год (обязательно).
4. Загрузить файл(ы) платежей:
   - **сбросы** — сверяются с колонкой «Сумма платы за сбросы, всего (080)»;
   - **выбросы** — сверяются с колонкой «Сумма платы за выбросы всего (040)».
5. «Сформировать сверку» → статистика на экране + скачивание Excel.

## Логика

- Колонки ищутся по заголовкам, лист с данными выбирается автоматически
  (для платежей — лист с «Сумма платёжного поручения», шапка может быть не в первой строке).
- Связка декларация ↔ платёж по **ИНН** (без учёта ведущих нулей);
  расхождение **КПП** — только флаг, платёж засчитывается.
- Кварталы: учитываются платежи с периодом `КВ.0{квартал}.{год}`; `МС.*` —
  засчитываются с пометкой «проверить»; прочие (КВ других кварталов/лет, ГД,
  СТРОЙКА…) — не учитываются, но видны на листе платежей серым.
- Год: учитываются все `КВ.*` и `ГД.*` указанного года, `МС.*` — с пометкой;
  нестандартные периоды (СТРОЙКА, ПО СУДУ, «?»…) — не учитываются.
- Платёж с пустым периодом засчитывается с пометкой «период не указан»;
  если колонки периода в файле нет вообще — учитываются все платежи.
- При нескольких декларациях на один ИНН в сводке учитывается декларация
  с максимальным № (последняя), дубли помечены флагом.
- Допуск сходимости суммы ±1 ₽.

## Итоговый Excel

| Лист | Содержимое |
|---|---|
| Сводка | счётчики и суммы по каждому типу |
| Декларации — сбросы/выбросы | декларации с суммой > 0 + статус сверки, цветовая разметка, автофильтр |
| Платежи — сбросы/выбросы | все платёжки + найденная декларация, ожидание 1/4, заметки |
| Должники — сбросы/выбросы | не оплатившие и недоплатившие, сортировка по остатку |

Цвета: зелёный — оплачено (±1 ₽), синий — переплата, жёлтый — недоплата,
красный — не оплачено / платёж без декларации, серый — не учтён по периоду.
